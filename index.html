Set up NFC sticker

Write this link to the sticker. Every time you tap your phone on it, a clock-in or clock-out will be recorded.

“Write sticker” only works in Chrome on Android. On iPhone, use the free NFC Tools app → Write → Add a record → URL, and paste the link.
